## Purpose

Close a review when every suggestion is settled, keep that text as a saved version, and let a new review start on it at any time (D-7).

## Requirements

1. Save is offered only when no suggestion is pending (S-2 Req 7).
2. Save marks every review in the current pass completed, collapses all current suggestions and margin notes, and freezes the text as a new saved version in the version history (S-8).
3. After Save the document reads clean: no marks, badge hidden, the status line shows the saved version.
4. Request review starts a new pass on the saved text: the model runs again and a new set of suggestions appears. Earlier saved versions are not changed.
5. Export of the latest saved version: Markdown, plain text and clipboard; for speeches also a large-type reading view and PDF with one paragraph per block.
6. The library shows each document's latest saved version and when it was saved.

## Out of scope

- Posting to blog platforms.
- A separate Publish state.

## Acceptance checks

- With 1 pending suggestion, Save is not shown.
- Save with 0 pending creates a new version and leaves no marks in the text.
- Request review after Save shows new suggestions and keeps the saved version unchanged in history.
- Markdown export of the latest saved version matches its text exactly.
