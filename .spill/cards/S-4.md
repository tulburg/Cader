## Purpose

Run text-only English editing models locally for proofreading, grammar, rephrasing, word substitution and sentence alternatives.

## Requirements

1. The models run fully on device inside Cader's Rust backend (D-6), with no server to install separately.
2. The models are downloaded from Hugging Face on first run with a progress bar, cached in the app data folder, and checksummed.
3. One API for every editing task: `correct(text)`, `rephrase(span, context, n)`, `substitute(span, context, n)`, `alternatives(sentence, n)`.
4. `correct()` answers a single sentence in under 1.5 s on this Mac (M2 Max, 64 GB). Rephrase, substitute and alternative options stream to the card one at a time: the first arrives in about 2.5 s, a full batch in about 3 s (rephrase), 6 s (alternatives) or 7 to 13 s (substitute, 5 words with notes). Measured on the 14B model at about 15.6 tokens/s, which is the hardware limit.
5. Requests are cancellable; a new request for the same span cancels the old one.
6. Two models (D-4, model size changed at the user's request): grammarly/coedit-large (ONNX, via the ort crate) serves `correct()`; Qwen2.5-14B-Instruct (GGUF Q4_K_M, via the llama-cpp-2 crate with Metal) serves `rephrase()`, `substitute()` and `alternatives()`. Replies are constrained to a JSON array so options can be de-duplicated.
7. The models are about 9.8 GB on disk (CoEdIT 0.8 GB, Qwen 9.0 GB), use about 11 GB of memory when loaded, and load lazily, so the app opens without waiting on them. They must run cleanly on the current machine (M2 Max, 64 GB).
8. CoEdIT-large is CC-BY-NC-4.0: fine for personal use; the About screen states it, and a commercial build would need a different correction model.

## Out of scope

- Fine-tuning or training a custom model in v1.
- Non-English languages.

## Acceptance checks

- First run downloads the models once; second run starts offline.
- `correct()` on a 20 word sentence with three errors returns it fixed in under 1.5 s.
- Cancelling a running request frees it within 200 ms.
- The 14B model loads and answers without memory pressure or swapping on the M2 Max.
