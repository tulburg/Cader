## Purpose

Revise a piece over several passes, with every pass saved as a version (D-7: Save closes a review; there is no separate Publish).

## Requirements

1. A review is one pass over the document: dictation, proofreading, and every applied suggestion until the user ends it with Save.
2. Each saved version stores the full text, the time, and a list of the changes made in that pass (accepted fixes, rephrases, substitutions, alternatives, manual edits).
3. The Versions panel lists versions newest first; opening one shows a readable diff against the previous version or any chosen one.
4. Any version can be restored as the working text (restoring creates a new version, nothing is lost).
5. Unsaved work in progress is autosaved and recovered after a crash.
6. Saved versions are never edited; work after a Save continues in the working draft, and the next Save adds the next version.

## Out of scope

- Branching versions.
- Sharing versions with others.

## Acceptance checks

- Three review passes produce three versions with correct change lists.
- Restoring v1 creates v4 equal to v1.
- Killing the app mid-review and reopening restores the unsaved text.
