Handy (Tauri app, MIT) has no API that returns transcripts. It records on a hotkey, transcribes, and pastes into the focused app. It does have `handy --toggle-transcription` to start/stop a running instance, and a transcription hook (an executable that gets the text on stdin; its stdout is what gets pasted).

- A. Paste: Cader's Dictate button runs `handy --toggle-transcription`, Handy pastes into Cader's focused editor (simplest, recommended for v1)
- B. Hook: install a Handy hook that also sends the text to Cader over a local socket, so text lands in the right document even if focus moved
- C. Embed: run Handy's transcription engine (Whisper via whisper.cpp) inside Cader as a sidecar and drop the Handy app dependency
