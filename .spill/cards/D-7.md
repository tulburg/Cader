There is no Publish step. The finishing action is **Save**: it marks every review completed, collapses all current reviews and suggestions, and freezes that text as a saved version. A new review can be requested on the saved text at any time, which starts a new set of suggestions. Save is shown only when no suggestion is pending (S-2).
